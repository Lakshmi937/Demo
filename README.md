# Famous Sports Carousel

A simple static web page showcasing a Bootstrap carousel that displays images of popular sports.

## Files

- `index.html` - Main HTML page.
- `style.css` - Custom styles for page layout and typography.

## Features

- Bootstrap 4 carousel with three slides.
- Uses Bootstrap CDN for layout and carousel functionality.
- Includes custom font styles via Google Fonts.

## Usage

1. Open `index.html` in a web browser.
2. The carousel will autoplay and can also be navigated using the prev/next controls.

## Dependencies

This page loads external resources from CDNs:

- Bootstrap 4 CSS and JS
- jQuery
- Popper.js
- Google Fonts

## Notes

- No build or install step is required.
- The page is fully static and works by opening the HTML file directly.
